갤럭시에서 Tasker 한 번에 가져오기

1. install.html 한 파일을 갤럭시로 옮겨 브라우저에서 엽니다.
2. "Tasker로 한 번에 가져오기"를 누르고 프로젝트 추가를 허용합니다.
3. 갤럭시에서 Tasker의 알림 접근 / 배터리 제한 없음을 허용합니다.
4. 웹 가계부에서 연결 설정을 복사합니다.
5. Tasker 작업 "BB 시작" → ▶ → 설정 붙여 넣기.
6. "BB 상태"와 웹 수신함의 [연결 시험]을 확인합니다.

앱 연결 버튼이 안 열리면:
- 설치 화면의 "프로젝트 파일 받기"를 눌러 Budget-Auto.prj.xml을 받습니다.
- Tasker 하단 프로젝트 탭을 길게 누르고 Import에서 해당 파일을 선택합니다.
- 첨부된 Budget-Auto.prj.xml을 직접 사용할 수도 있습니다.

추가 스크립트 복사나 유료 플러그인은 필요하지 않습니다.
알림이 없던 과거 거래를 가져오는 기능은 아닙니다.
이체·플러스박스 이동·환불은 자동 지출로 더하지 않습니다.

현재 상태 (2026-10-16):
- PC에서 XML 구조, 코드, 설치 화면 검증 완료
- 실제 Tasker 가져오기 / 알림 / 쿠팡이츠 화면 추출은 미검증
- Supabase SQL 및 웹 기능은 아직 운영 반영 전
- 따라서 현재는 가져오기와 권한 준비까지만 할 수 있습니다.
- 실제 서버 시험 성공 전에는 새 알림 수집을 시작하지 않습니다.

이 파일들에는 비밀 연결키가 없습니다.
