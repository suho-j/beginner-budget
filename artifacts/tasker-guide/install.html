Tasker가 설치된 갤럭시에서 열어 주세요. 케이뱅크·쿠팡이츠 알림, 실패 시 재전송, 연결 시험이 함께 들어갑니다.

가계부 서버 연결 준비 완료
서버 수신 시험을 통과했습니다. 아래 순서대로 연결해 주세요. 실제 갤럭시 알림 수신은 폰에서 확인해야 합니다. 내 폰의 연결 시험에 성공한 뒤 새 알림을 수집합니다.

웹 가계부 열기 · 연결 설정 만들기 (새 창)

  1. 가져오기 허용
    Tasker에 가계부 자동수집 프로젝트를 추가하고 프로필 활성화를 허용하세요. 기존 설정 전체를 복원하는 메뉴는 사용하지 않습니다.
  2. 알림 접근 허용
    갤럭시 설정에서 알림 접근을 검색해 Tasker를 허용하세요. Tasker의 배터리 설정도 제한 없음으로 설정합니다.
  3. 연결 설정 한 번 붙여 넣기
    가계부 설정 → 휴대폰 알림 연결 → 연결 설정 만들기에서 복사한 뒤, Tasker 작업 BB 시작을 열고 ▶를 누르세요. 붙여 넣으면 연결 시험이 실행됩니다.
  4. 시험 성공 확인
    BB 상태 → ▶로 브라우저에서 연결 시험 기록을 확인하고 가계부 수신함의 [연결 시험] 한 건을 확인하세요. 실제 결제는 만들지 않습니다.

기존 설치에서 상태창이 안 뜨면 연결 확인 작업만 추가하세요. 연결 설정을 다시 입력하지 않아도 됩니다.

파일로 가져오려면

받은 파일 이름은 Budget-Auto.prj.xml입니다. Tasker 하단의 프로젝트 탭(집 아이콘 또는 프로젝트 이름)을 길게 누르고 Import / 가져오기에서 이 파일을 고르세요. 같은 이름의 프로젝트가 이미 있으면 중복으로 추가하지 마세요.

쿠팡이츠 메뉴도 보내려면

알림은 자동 수집합니다. 메뉴가 알림에 없을 때는 Tasker 설정의 Action → Quick Settings Tasks 빈 칸에 BB 주문 화면을 지정하고 갤럭시 빠른 설정에 해당 Tasker 타일을 추가하세요.

쿠팡이츠 주문 상세를 열고 타일을 누르면 화면 글자를 확인한 뒤 보냅니다. Tasker를 기본 디지털 어시스턴트로 지정해야 할 수 있으며, 앱이 화면 글자를 제공해야 합니다. 실제 쿠팡이츠 화면 추출은 아직 검증 전입니다.

어떤 내용이 가계부에 들어가나요?

설치 이후 케이뱅크·쿠팡이츠가 표시한 알림을 수신함에 모읍니다. 과거 내역을 조회하지는 않습니다. 알려진 잔액·번호 표기를 가리고 인증번호 알림은 보내지 않습니다.

이체·플러스박스 이동·환불은 자동 지출로 더하지 않습니다. 카드 결제 후보도 사람이 확인해야 지출이 됩니다. 쿠팡 주문 자동 조회와 카테고리 자동 확정은 이번 설치에 포함되지 않습니다.

프로젝트에는 개인 연결키가 없습니다. 연결키는 휴대폰에서 입력합니다.
