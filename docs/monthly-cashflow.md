# 월 현금흐름 계획

현금흐름 탭에서 선택한 달의 수입, 고정 납부, 용돈, 목적 적립, 기존 저축과 생활비 예산을 입력한다.

- 먼저 확보할 돈 = 고정 납부 + 용돈 + 목적 적립 + 기존 저축
- 생활비 + 추가 저축 = 월 수입 − 먼저 확보할 돈
- 추가 저축 가능액 = 생활비 + 추가 저축 − 생활비 예산

음수이면 예산 초과 안내를 표시한다. 계산은 계획 기준이며 계좌 잔액 또는 실제 지출과 자동 대조하지 않는다. 계좌 간 이체와 카드 대금은 원래 지출과 중복 입력하지 않는다. 공동 부담금은 본인 부담액을 입력한다. 대출 상환은 현금 유출이므로 원리금 납부액을 포함한다.

## 사용

1. 상단에서 월을 고르고 현금흐름 탭을 연다.
2. 항목을 추가하거나 이전 달 계획을 복사한다.
3. 생활비 예산을 입력하고 결과를 확인한다.
4. 로그인 후 이 달 계획 저장을 누른다. 저장 실패 시 입력은 유지된다.

계획 파일 불러오기는 아래 형태의 JSON을 현재 달 입력란에 불러온다. 저장 버튼을 눌러야 확정된다. 실제 거래와 기존 생활비 예산 설정은 변경하지 않는다.

```json
{"items":[{"name":"급여","kind":"income","amount":3000000}],"livingBudget":1000000}
```

구분: `income`, `fixed`, `allowance`, `reserve`, `saving`. 항목 최대 100개, 항목명 1–80자, 금액 0–2147483647원 정수. 개인 재무 데이터는 공개 저장소에 넣지 않는다.

## 고정비 점검

현금흐름 탭의 **고정비 점검**에서 이번 달 고정 납부 합계와 수입 대비 비율을 확인한다. **고정비만 보기**는 화면만 좁히며 수입·다른 배분 항목도 계산과 저장에 유지한다.

고정 납부 행의 상세를 열어 납부일(예: `25일~말일`), 결제수단, 점검 상태, 목표 월 금액, 메모를 입력한다. 납부일과 결제수단은 참고용이며 자동결제나 반복지출을 생성하지 않는다.

- **유지**: 기본값. 목표금액이 있어도 예상 절감액에 합산하지 않는다.
- **검토 중**: 약정·보장 등 확인 단계. 아직 절감액으로 합산하지 않는다.
- **절감 예정**: 현재 금액 이하의 목표금액을 입력해야 한다. 해지 예정은 0원으로 입력한다.
- 월 예상 절감액 = 절감 예정 항목의 현재 금액 − 목표금액 합계. 연간 수치는 같은 절감액을 12개월 유지할 때의 예상이다.
- 절감 후 추가 저축 가능액 = 현재 추가 저축 가능액 + 월 예상 절감액. 현재 현금흐름과 실제 거래에는 미리 반영하지 않는다.
- 변경이 실제 적용되면 현재 월 금액을 바꾸고 상태를 유지로 전환한다. 보험 등 필요한 항목을 자동으로 절감 대상으로 지정하거나 일률적인 적정 비율을 제시하지 않는다.

고정 납부 항목에만 선택 필드 `fixedCost`를 저장한다. 기존 계획은 필드 없이 그대로 불러올 수 있다. 이전 달 복사·계획 가져오기·전체 백업·클라우드 왕복에서 메타데이터를 보존한다.

```json
{"name":"통신비","kind":"fixed","amount":50000,"fixedCost":{"status":"reduce","targetAmount":30000,"paymentDay":"25일","paymentMethod":"카드","memo":"약정 확인 후 변경"}}
```

`status`: `keep`, `review`, `reduce`. `targetAmount`: 금액 또는 `null`(미정). `paymentDay`·`paymentMethod` 각 40자, `memo` 200자. 고정 납부가 아닌 구분으로 변경해 저장하면 고정비 상세는 제외한다.

## 저장 및 호환성

`cashflowPlans[YYYY-MM]`을 정규화하며 Supabase 기존 설정 JSONB `category_budgets.__cashflow_plans`에 저장한다. 별도 스키마 변경 없이 기존 설정 충돌 보호를 사용한다. 미리보기와 운영 데이터 분리를 유지한다. 전체 JSON 백업에 계획이 포함된다. 전체 백업 복원은 기존의 전체 교체 동작을 유지하므로 계획만 가져올 때는 현금흐름 탭의 파일 불러오기를 사용한다.

배포 후 열려 있던 오래된 앱 탭은 새로고침해야 새 필드를 보존한다.

## 검증

- `node tests/run-tests.cjs`: 기존 회귀 테스트
- `node tests/cashflow.test.cjs`: 금액 검증, 계산, 클라우드 매핑, 백업
- `node tests/fixed-cost.test.cjs`: 고정비 메타데이터 검증, 기존 계획 호환, 상태별 예상 절감액, 0원 목표, 클라우드·백업 보존
- `node tests/cashflow-browser.cjs`: Playwright 설치 필요. 고정비 상세/필터/예상액, 파일 입력, 저장 성공/실패, 월별 분리, 이전 달 복사, 저장 중 잠금, 360px 레이아웃, 로그아웃 확인. 클라우드는 모의 API이며 실제 계정 데이터는 수정하지 않는다. 시스템 Chromium 사용 시 `CASHFLOW_CHROMIUM_PATH`로 지정할 수 있다.
