# 월 현금흐름 계획

현금흐름 탭에서 선택한 달의 수입, 고정 납부, 용돈, 목적 적립, 기존 저축과 생활비 예산을 입력한다.

- 먼저 확보할 돈 = 고정 납부 + 용돈 + 목적 적립 + 기존 저축
- 생활비 + 추가 저축 = 월 수입 − 먼저 확보할 돈
- 추가 저축 가능액 = 생활비 + 추가 저축 − 생활비 예산

음수이면 예산 초과 안내를 표시한다. 계산은 계획 기준이며 계좌 잔액 또는 실제 지출과 자동 대조하지 않는다. 계좌 간 이체와 카드 대금은 원래 지출과 중복 입력하지 않는다. 공동 부담금은 본인 부담액을 입력한다. 대출 상환은 현금 유출이므로 원리금 납부액을 포함한다.

## 사용

1. 상단에서 월을 고르고 현금흐름 탭을 연다.
2. 항목을 추가하거나 이전 달 계획을 복사한다.
3. 생활비 예산을 입력하고 결과를 확인한다.
4. 로그인 후 이 달 계획 저장을 누른다. 저장 실패 시 입력은 유지된다.

계획 파일 불러오기는 아래 형태의 JSON을 현재 달 입력란에 불러온다. 저장 버튼을 눌러야 확정된다. 실제 거래와 기존 생활비 예산 설정은 변경하지 않는다.

```json
{"items":[{"name":"급여","kind":"income","amount":3000000}],"livingBudget":1000000}
```

구분: `income`, `fixed`, `allowance`, `reserve`, `saving`. 항목 최대 100개, 항목명 1–80자, 금액 0–2147483647원 정수. 개인 재무 데이터는 공개 저장소에 넣지 않는다.

## 저장 및 호환성

`cashflowPlans[YYYY-MM]`을 정규화하며 Supabase 기존 설정 JSONB `category_budgets.__cashflow_plans`에 저장한다. 별도 스키마 변경 없이 기존 설정 충돌 보호를 사용한다. 미리보기와 운영 데이터 분리를 유지한다. 전체 JSON 백업에 계획이 포함된다. 전체 백업 복원은 기존의 전체 교체 동작을 유지하므로 계획만 가져올 때는 현금흐름 탭의 파일 불러오기를 사용한다.

배포 후 열려 있던 오래된 앱 탭은 새로고침해야 새 필드를 보존한다.

## 검증

- `node tests/run-tests.cjs`: 기존 회귀 테스트
- `node tests/cashflow.test.cjs`: 금액 검증, 계산, 클라우드 매핑, 백업
- `node tests/cashflow-browser.cjs`: Playwright 설치 필요. 파일 입력, 저장 성공/실패, 월별 분리, 이전 달 복사, 저장 중 잠금, 360px 레이아웃, 로그아웃 확인. 클라우드는 모의 API이며 실제 계정 데이터는 수정하지 않는다.
