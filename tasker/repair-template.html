가계부 자동수집 · 수정판 2

연결키는 그대로,
두 작업만 교체하세요.

상태를 읽어도 오류 화면이 남는 문제와 알림 재전송의 변수 전달을 수정했습니다. 브라우저 선택 칸에 잘못 들어가던 %도 제거했습니다.

수정 작업 가져오기 앱이 열리지 않으면 수정 파일 받기
  1. 가계부 연결 수정 프로젝트를 가져옵니다.
  2. 같은 이름의 작업을 교체할지 물으면 BB 연결 확인과 BB 보내기의 덮어쓰기를 허용합니다.
  3. Tasker에서 작업 → BB 연결 확인 → ▶를 누릅니다. 결과에 진단 수정판 2가 표시되는지 확인하세요.

기존 알림 프로필과 연결 설정은 유지합니다. 연결키를 다시 입력하거나 ‘BB 시작’을 다시 실행할 필요가 없습니다. BB 보내기는 기존 대기 알림을 같은 연결로 전송하며 서버 성공 응답을 받은 건만 대기열에서 지웁니다.

파일로 가져오기

Tasker 하단 프로젝트 탭을 길게 누른 뒤 Import에서 Budget-Repair.prj.xml을 선택하세요. 전체 설정 복원 메뉴는 사용하지 않습니다.

이름 중복으로 가져오기가 막히면

기존 프로젝트나 대기열을 지우지 말고 표시되는 문구를 알려주세요. 덮어쓰기 안내는 Tasker 공식 공유 문서를 기준으로 했으며 실제 폰의 수정 파일 가져오기는 확인이 필요합니다.

연결 확인 안내 보기

연결키가 포함되지 않은 수정 파일입니다. PC에서 변수 전달 재현·회귀 테스트와 웹 화면을 검증했습니다. 폰에서의 교체·수신 성공은 결과를 확인한 뒤 판단합니다.
