가계부 자동수집 · 연결 복구 수정판 3

남은 알림을 보존하며
새 연결로 복구하세요.

‘이전 연결의 미전송 알림이 있어요’에서 멈췄다면 아래 순서로 진행하세요. 새 연결키를 만든 뒤 이전 키로 전송하라고 안내하던 문제를 수정했습니다.

수정 작업 가져오기 앱이 열리지 않으면 수정 파일 받기
  1. 가계부 연결 수정 프로젝트를 가져옵니다. 기존 프로젝트와 변수는 삭제하지 마세요.
  2. 같은 이름의 작업을 교체할지 물으면 BB 연결 확인과 BB 보내기의 덮어쓰기를 허용합니다.
  3. 가계부에서 가장 최근 만든 연결 설정을 복사합니다. 이미 복사해 두었다면 다시 만들지 않아도 됩니다.
  4. Tasker에서 작업 → BB 연결 복구 → ▶를 누르고 붙여 넣으세요. 같은 계정·같은 가계부에서 복사한 설정이면 미전송 알림을 보낼까요? 안내에서 확인을 누릅니다.
  5. 전송 후 BB 연결 확인 → ▶에서 미전송 알림 0개인지 확인하고, 가계부의 받은 알림 불러오기에서 새 [연결 시험]을 확인하세요.

가져오기만으로 연결이 바뀌지는 않습니다. 복구를 실행하고 확인하면 기존 대기열을 폰에 백업한 뒤 연결을 변경합니다. 남은 알림은 내용·ID를 유지하며 서버 성공 응답을 받은 건만 대기열에서 지웁니다. 기존 알림 프로필은 유지합니다.

새 연결키를 만들지 않았다면

복구를 실행할 필요 없이 BB 보내기 → BB 연결 확인 순서로 실행하세요. 이 파일에는 이전 수정판의 전송·진단 수정도 포함돼 있습니다.

‘BB 보내기가 실행 중’이라고 나오면

최대 1분 기다린 뒤 다시 복구하세요. 계속 같은 안내가 나오면 Tasker의 실행 중인 작업 화면을 확인해야 합니다. 대기열이나 프로젝트는 지우지 마세요.

파일로 가져오기

Tasker 하단 프로젝트 탭을 길게 누른 뒤 Import에서 Budget-Repair.prj.xml을 선택하세요. 전체 설정 복원 메뉴는 사용하지 않습니다.

이름 중복으로 가져오기가 막히면

기존 프로젝트나 대기열을 지우지 말고 표시되는 문구를 알려주세요. 덮어쓰기 안내는 Tasker 공식 공유 문서를 기준으로 했으며 실제 폰의 수정 파일 가져오기는 확인이 필요합니다.

연결 확인 안내 보기

연결키가 포함되지 않은 수정 파일입니다. PC에서 변수 전달 재현·회귀 테스트와 웹 화면을 검증했습니다. 폰에서의 교체·수신 성공은 결과를 확인한 뒤 판단합니다.
